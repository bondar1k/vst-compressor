# Lineage — Vintage Compressor Collection (VST3 / Standalone)

Пять режимов, эмулирующих поведение легендарных компрессоров:

| Режим    | Прототип по духу          | Детектор | Особенности                                              |
|----------|---------------------------|----------|----------------------------------------------------------|
| FET      | быстрый FET-лимитер       | peak     | атака от 20 мкс, жёсткий колено, нечётные+чётные гармоники |
| OPTO     | электрооптический леveler | RMS      | атака >= 8 мс, программно-зависимый релиз с "хвостом"    |
| VCA BUS  | VCA шинный компрессор     | peak     | чистый feed-forward, мягкое короткое колено              |
| VARI-MU  | ламповый variable-mu      | RMS      | ratio растёт с глубиной сжатия, трансформаторная окраска |
| RMS      | true-RMS компрессор       | RMS      | линейный по дБ релиз, over-easy колено                   |

Общие ручки: Input, Threshold, Ratio, Attack, Release, Output, Mix (параллельная компрессия),
SC HPF (фильтр сайдчейна), Character (насыщение с ADAA-антиалиасингом), Auto Makeup.
При выборе модели подставляются её типичные стартовые значения.

## Сборка

Нужны: CMake >= 3.22, компилятор C++17, git (JUCE скачается автоматически).

    cmake -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --config Release

VST3 копируется в системную папку плагинов автоматически (COPY_PLUGIN_AFTER_BUILD).
Для проверки без DAW запускайте Standalone-версию из build/Lineage_artefacts.
Для AU (macOS) добавьте AU в FORMATS в CMakeLists.txt.

## Заметки
- Это эмуляция поведения (кривая, детектор, временные константы, насыщение), а не схемотехническая модель.
- Названия моделей в интерфейсе нарочно нейтральные; прототипы указаны только как ориентир.
